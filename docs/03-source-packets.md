# 史料包规范

当前任务：编制并核验听写测试与Kisch两套双语材料。

每包拟为400至500英文词，中文版本逐项对应。按实际材料划分约6至8个信息单元，覆盖法律程序、实施者、目的与后果、人物及回应。

## 来源

听写测试从[1927年实施通函原文转录](https://www.naa.gov.au/students-and-teachers/learning-resources/learning-resource-themes/society-and-culture/migration-and-multiculturalism/directions-applying-dictation-test-home-and-territories-department)入手，并补充具体移民经历和行动。

Kisch材料核对相关裁判、行政决定与个人回应。[国会法律图书馆历史解释](https://blogs.loc.gov/law/2015/12/on-this-day-establishment-of-the-white-australia-policy/)提供检索线索，案件顺序和裁判理由以原始材料核验。

## 信息登记

每项记录作者、日期、标题、来源类型、稳定URL、定位、访问日期及阅读范围。原文、译文和研究者转述分别保存。每个信息单元设unit_id，登记行动者、事实及可接受的压缩方式。

## 双语与顺序

核对行动者、因果、义务、许可、目的、否定、时间与理由归属。两个语言版本保持信息单元一致。

O1按制度与人物行动两个块排列，O2交换块的位置，保留块内文字和来源标签。各块按史料内容呈现，材料包作为完整语言条件进入分析。

## 冻结

材料全文、出处、信息单元、译文和顺序版本核验后生成版本号与校验值，并替换B组占位符。上传材料时核对保存与分享权限。
