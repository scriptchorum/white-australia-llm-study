# 试采集与冻结

当前未调用任何模型。试采集与正式采集均须在用户明确要求执行后开始。

## 十二份技术试采集

两个模型、两种语言、每组合三个任务，共12份。为同时验收材料管线，建议三个任务为A-W-G1、A-D-P1、B-D-O1-G，而非全部为无材料G题。此选择是对早稿试采集清单的明确修订，不改变120份正式设计；B材料未完成时，完整试采集仍未就绪。

试采集检验API身份、设置、上下文隔离、双语理解和长度、材料注入、归档、计费及技术失败处理。不以支持或反对理论作为验收条件。试采集独立保存，不计入正式120份。

## 验收项目

- 实际请求消息和角色正确，无前文及分析标签。
- 两家实际型号/模式/可见设置已记录，没有静默自动路由或未记录的参数回退。
- B材料完整、版本正确、无占位符；材料顺序确实与预定版本一致。
- 中英文任务范围一致，没有一方多出评价词；长度没有造成明显单方面信息压缩。只能认为完成了有限检查，不宣称等价已被证明。
- 完整响应和状态可恢复，能定位计费token与费用估算，错误不会覆盖有效结果。
- 拒答、反例、短答能被保留，而非触发语义择优重试。

## 正式冻结

形成protocol、prompt、source、codebook和config版本；保存内容校验值与运行清单。提示和材料的修改说明可追踪。冻结后新增题目、改变模式或编码标准需标新版本，不能倒写成事先设计。

任何尚未核实的材料、无法访问的模型、缺失的API身份或隔离失败，都不以虚构字段补齐。先处理实际缺口再采集。
