# 预算与数据归档

## 费用

规划API消耗预算为30至50元，执行前核对型号、单价、账户与支付条件。以GPT-6.1 Sol和DeepSeek V4 Pro为规划示例，120份回答、平均每份输入1500及计费输出1200 tokens的估算约9元。12份试采集另计，实际用量随材料、推理与技术重试调整。

[OpenAI官方价格](https://developers.openai.com/api/docs/pricing)、[DeepSeek官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

记录实际usage、原币费用、规划汇率和人民币估算；输入、缓存及计费输出分别登记，推理消耗按账单规则计入。拟设50元客户端停止阈值，每次请求前检查已用费用和下一次保守估算，输出上限与平台计费设置同时核实。达到阈值时暂停批次，保持冻结型号和任务，后续执行由用户决定。

## 记录

每次保存run_id、批次、prompt_id、语言、提示/材料/配置版本、时间、请求与返回模型、完整输入、原始响应、可见推理、完成状态、请求ID、token、费用及重试链。

凭据使用本机密钥管理；原始数据、分析稿和版本记录分别保存。语义判断在分析副本完成，原始回答保持原样。

## 保存位置

仓库保存方案、提示、配置模板和空白记录。原始数据分别存本地data/pilot和data/formal，分析放outputs/analysis，凭据保存在本机配置。Git忽略规则覆盖这些本地目录，备份位置另记。

材料分享根据版权、隐私、匿名要求和用户决定安排。
