# 预算与数据归档

## 预算

用户接受的API消耗预算估算为30至50元。它不是已发生费用、最低充值额或服务访问保证。账号、具体模型、价格、计费设置及支付条件在执行前再核对。

讨论中的示例模型为GPT-6.1 Sol与DeepSeek V4 Pro，尚未完成可用性与配置冻结。此前对120份、每份平均输入1500及计费输出1200 tokens的估算约9元；该数字仅供规划，推理消耗、材料长度、重试和价格变化会改变结果。12份试采集另计，预计数量级较小，不能当作零费用。

[OpenAI官方价格](https://developers.openai.com/api/docs/pricing)

[DeepSeek官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

执行程序应按实际usage累计，不只按答案字数。输入、缓存及计费输出分别记录，含可计费推理。记录美元原额及预算换算假设，不把规划汇率写成实时结算汇率。不计未获确认的免费额度或折扣。

拟设50元客户端累计停止阈值，每次新请求前检查当前消耗和下一次保守估算；设置适当输出上限以减少单次超额。客户端估算不是供应商账单的绝对硬上限，实际平台限制另行核实。不得通过自动换模型或缩短正式任务来保住预算。

## 数据记录

每次请求记录run_id、批次pilot/formal、prompt_id、语言、配置/材料版本、请求时间、model_requested及model_reported、端点、完整客户端指令/输入、原始响应、可见推理字段、finish状态、请求ID、token用量、估算费用、技术错误及重试链。

不记录Authorization头、API密钥、账号密码或凭据。历史内容与语义失败不得覆盖。分析稿与原始数据分开，记录每次改判。材料、提示、配置用版本标识，不以当前文件名猜测生成时版本。

## 仓库边界

本次只上传文档、提示与空模板。data/raw、data/pilot、data/formal、outputs、local、.env和日志默认被Git忽略；以后即使仓库仍私有，也不自动提交这些目录。没有开放数据承诺；分享或公开需单独决定。

未来归档建议为本地data/pilot与data/formal，研究者分析放outputs/analysis。待核对版权、隐私和匿名要求后再确定可交付材料。不要把排除在Git外误称为已安全备份，实际备份位置要记录。
