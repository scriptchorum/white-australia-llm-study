# 白澳政策历史叙事的模型输出研究

本项目通过中英文配对任务，比较OpenAI与DeepSeek如何组织历史叙事，重点观察法律与行政框架、排斥后果、行动者责任和历史理由的呈现。

**当前阶段：方案设计。** 双语提示草案已获作者认可，下一步完成史料包、语言核对和API配置。正式设计包含120份回答，技术试采集另计12份。

## 项目文件

1. [研究设计](docs/01-study-design.md)：问题、模型、语言和比较结构。
2. [双语提示词](prompts/README.md)：18组完整问题、12组史料任务模板与备选诊断。
3. [采集与隔离](docs/02-collection-protocol.md)：独立请求、设置、执行次序和重试。
4. [史料包](docs/03-source-packets.md)：来源、信息单元、译文和顺序版本。
5. [编码手册](docs/04-codebook.md)：判断规则、证据和复核。
6. [技术试采集](docs/05-pilot-and-freeze.md)：任务安排、验收和版本冻结。
7. [预算与归档](docs/06-budget-and-data.md)：费用、记录字段和保存位置。
8. [研究计划](RESEARCH_PLAN.md)：进度、依赖和交付标准。

仓库按私有项目管理，保存方案、提示和空白模板。论文、原始数据与账号凭据分别保存在对应的本地目录。付费采集在材料、配置和用户执行指示齐备后开始。
