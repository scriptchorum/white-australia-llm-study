# 白澳政策历史叙事的模型输出研究

本项目整理一项探索性比较研究的方案、提示词和执行规范，考察模型如何通过法律与行政框架组织历史，以及这种组织何时呈现或弱化排斥、伤害和责任。

**当前状态：设计阶段，未运行模型，未产生实验数据。** 提示草案已经作者认可；史料包、双语核对、具体API版本和采集设置尚未冻结。仓库创建及上传不等于授权调用付费API、公开论文或实施正式采集。

计划比较OpenAI与DeepSeek的明确API版本，两者均做中文和英文任务。每个模型每种语言包含18条无材料任务及12条固定材料任务，合计120份正式回答。拟另作12份技术试采集并独立保留，计划成功请求共132份；技术重试另记。这个规模不是统计功效计算结果，回答也不是独立历史案例。

## 仓库范围

只保存研究方案、提示词、空白记录模板和材料清单。不包含论文正文、旧稿摘录、审稿邮件、原始会话、云盘导出、账号凭据或API密钥。项目当前按私有仓库管理，未指定开源许可。

没有自动运行模型的代码、GitHub Actions或付费调用任务。历史材料尚未编成前，带占位符的B组模板不得执行；六条备选诊断问题不计入120份，不能看到结果后选择性追加。
